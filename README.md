# Cuervo Dice Engine

Lanzador de dados para la campaña **Las Cenizas de la Marea**.

## Uso

La aplicación permite lanzar d4, d6, d8, d10, d12, d20 y d100; configurar entre 1 y 20 dados; sumar un modificador; y resolver ventaja o desventaja para 1d20. Muestra cada resultado, el total, permite copiar la tirada y conserva un historial local de hasta 40 resultados.

## Publicación con GitHub Pages

En el repositorio, abrí **Settings → Pages**. En **Build and deployment**, elegí **Deploy from a branch**, seleccioná la rama **main** y la carpeta **/(root)**, y guardá. Cuando GitHub termine de publicar, la aplicación estará disponible en la URL que indique esa sección.

Los resultados se generan en el navegador mediante Web Crypto. La aplicación no envía automáticamente tiradas a ChatGPT ni a GitHub.
